CLASIFICADOR DE FUNCIONES DE PRIMER GRADO

b = [ Random (-3 a 3) ]
c = [ Random (-3 a 3) ]

LINEAL

Muestra sus propiedades cuando c = 0 y b ≠ 0.

AFÍN

Muestra sus propiedades cuando b ≠ 0 y c ≠ 0.

CONSTANTE

Muestra sus propiedades cuando b = 0.

SIN FUNCIÓN

Solo aparece si b o c no son números válidos.
